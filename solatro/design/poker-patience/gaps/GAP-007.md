## What the design says

`PLAN.md` §1.9: *"`TypeInput` keeps its class; **only `on_next` is removed**."*

`PLAN.md` §1.11, on archiving at S19: the tableau cards leave the default rules deck, and
*"Their tests move with them and no longer run in the suite"* (`Q210`).

`TEST_PLAN.md` TP-79's done-when: *"suite count drops by exactly the moved suites and **no
other suite changes**."*

## What the repo says

Removing `TypeInput.on_next` removes the **legacy deal** — drop each Entrance column into its
paired lower column, then draw. Measured: that breaks **20 checks across six suites**.

| suite | failing checks |
|---|---|
| E2E RUN | 5 |
| MODS | 4 |
| LEAK CANARY | 4 |
| VISUAL LAYERS | 3 |
| UI PROPS | 2 |
| INTERACTION | 2 |

None of these are tableau CARD tests. They are general suites — an end-to-end run, prop
animation, the leak canary, visual layering, touch input — that use the tableau deal as
**scaffolding to get cards onto a board at all**. When the tableau goes, they have no board.

## What it does not say

`Q210` moves *"their tests"* with the archived cards, which plainly covers the grabber's and
the placer's own suites. It says nothing about suites that merely USE the tableau to set up.
And TP-79 requires **no other suite changes**, which these six unavoidably need.

So two documented requirements point opposite ways: the archive must not disturb other suites,
and six other suites cannot survive the archive untouched.

## Why it matters

This is not a tidy-up. Rebuilding six suites onto the grid game is real work that no step owns,
and it is the difference between "the tableau is archived" and "the game still has a tested
end-to-end path". `LEAK CANARY` and `E2E RUN` in particular are the only checks that a whole
show runs start to finish without leaking — exactly the guarantee `TP-130` also wants.

## Options I can see

- **(a)** Rebuild all six on the grid game as part of S19 — the archive step grows to include
  re-scaffolding every suite that used the tableau to deal. Most honest, largest, and TP-79's
  "no other suite changes" has to be rewritten because it is no longer achievable.
- **(b)** Keep a minimal tableau alive purely as test scaffolding — the lower zone and its
  adders stay constructible from the archive builder, and the six suites keep using it while
  the SHIPPED rules deck no longer includes it. Cheapest, and TP-79 stands as written; costs a
  second board model living on in the tests indefinitely.
- **(c)** Retire the six suites' tableau-dependent cases with the tableau and accept the
  coverage loss until the grid game's own end-to-end path exists (S37's TP-130, TP-128). Least
  work now; leaves the run with no end-to-end or leak coverage in between, which is precisely
  when a large refactor is landing.
- **(d)** Split: rebuild the two that guarantee the whole-show path (`E2E RUN`, `LEAK CANARY`)
  onto the grid game in S19, and let the other four follow the tableau into the archive.
