# GAP-007 — `on_mark_hit` hands level 2 to every property of a card, but a property's level 2 is unlocked by its own match only
status: open
raised: during the effect-review level-2 pass (`solatro/HANDOFF_effect_review.md` S14)
design: solatro/design/board-plan/DESIGN.md version 1, nodes Q33, Q35, Q47, Q50; PLAN.md §1.7
severity: CONTRADICTION

**What the design says** — `PLAN.md` §1.7: `on_mark_hit(card, coord, matched, level)` is dispatched
to the mark's modifiers and the placed card's, with `level` 0 (normal) or 1 (the realized form).

**What the owner has since ruled** (`solatro/todo.md`, the effect-review level-2 item), verbatim:
*"A match is same kind to same kind: suit to suit, rank to rank, hat to hat, skill to skill. A
property's level 2 is unlocked by its own match only."*

**What the engine does** — `Levels/game.gd` `_run_mark_hooks` calls
`run_mark_mods(card, MARK_HIT, card, coord, matches[card], 1)`, and
`CardEnvironment.run_mark_mods` passes that one `level` to EVERY modifier on the card. A card whose
rank matched hands `level == 1` to its skill and its stamp too. `matched` carries the bitmask, so a
modifier CAN test its own bit — but then `level` says nothing `matched` does not, and every effect
must remember to ignore it.

**Why it blocks** — nothing ships a level-2 effect yet, so nothing is wrong on screen; the first
content written to the effect review's level-2 forms would fire on the wrong match.

**Options I can see** —
**(a)** **`level` becomes per modifier**: `run_mark_mods` passes 1 only to the modifier whose slot's
`MarkMatch` property bit is set in `matched` — consequence: one dispatch change and a test per slot;
content reads `level` and nothing else ·
**(b)** **keep `level` card-wide and require each effect to test its own bit of `matched`** —
consequence: no engine change; every level-2 effect repeats the same check, and forgetting it is a
silent bug ·
*my recommendation* (a).

**Blast radius** — `Levels/game.gd` `_run_mark_hooks`, `Scripts/card_environment.gd`
`run_mark_mods`, `Tests/Engine/test_mark_match.gd`, board-plan `PLAN.md` §1.7 and
`ARCHITECTURE_REVIEW.md` §3e.

**Meanwhile** — the effect review writes level-2 forms against the owner's ruling; no engine change.
