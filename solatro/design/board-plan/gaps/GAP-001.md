**What the design says** — §1l-bis: *"The deck is no longer one pile — the Entrance is five stocks,
and that is already decided"*; `Q93`=(b) draws the marks *"evenly from each stock"*; `PLAN.md` §1.2:
*"stocks := the Entrance's per-slot stocks # sidebar QR9=a"*, *"Stratified by stock, exactly

**What the ANSWER says** — `Q79`, verbatim: *"out of scope, already in the sidebar design plan which
will run first"*. The sidebar plan's per-slot stocks are its Phase 6, step S19, and the sidebar run
in progress stops at S18 (`solatro/HANDOFF_sidebar.md` on branch `sidebar`: *"Phases 6–9 (S19–S24)
are NOT in this run"*). Neither `main` nor `sidebar` has any stock identifier
(`git grep -il stock -- solatro/Scripts solatro/Levels solatro/UI solatro/Cards` is empty on both).
So the premise "runs first" holds for the sidebar's container work and not for the stocks this
deal reads.

**What it does not say** — what the deal reads as its stock list while `GameData.draw_deck` is
still one pile, and whether TP-05/TP-06 wait for S19 or are proven against something else.

**Why it blocks** — TEST_PLAN: *"You may not decide a planned test is unnecessary. Dropping one is a
gap, not a judgement call."* TP-05 and TP-06 cannot be written against a board with one stock.

**Options I can see** —
**(a)** **the deal reads one stock today — `draw_deck`, which §1l-bis says IS the stocks' union — and
TP-05/TP-06 are parked until sidebar S19 lands, then written unchanged** — consequence: every other

until S19 there is no lane to starve, so nothing observable differs ·

way sidebar §1.7 will, deleted when S19 lands — consequence: TP-05/TP-06 pass now against a
partition the sidebar branch will implement a second time; two branches carry the same rule ·
**(c)** **park S4 and everything after it until S19 lands on `main`** — consequence: this run
delivers S1–S3 and stops ·
*my recommendation* (a). The run proceeds on (a) as an assumption because it is reversible in one
line; the OPEN part of this gap is only whether TP-05/TP-06 wait for S19 or (b) is wanted now.
