# GAP-004 — inside a viewer, which card size is "the board's own card size"?
status: open
raised: during S12 (Phase 3 review)
design: DESIGN.md version 10, nodes L11, C5; answer Q34
severity: OWNER CALL (look)

**What the design says** — `Q34` ⚑contract, chosen (b): *"at the board's own card size, so it reads
as the same object"*. It was asked about the board, before `Q140`=(a) sent the deck, discard, rules
and choice viewers into the same sidebar. Those viewers draw their cards at their own sizes: the
deck viewer at twice a board card, the booster pack at its own.

**What the ANSWER says** — nothing about a viewer. The rationale, *"so it reads as the same
object"*, can be read two ways once the object pointed at is a viewer card.

**What it does not say** — whether a description opened from a viewer draws its preview at the
BOARD's card size (one size for every description, a smaller card than the one under the pointer
in the deck viewer) or at the VIEWER's card size (matches the object pointed at; the preview
changes size between the board and each viewer, and a resize while a viewer entry is up must
re-draw at the viewer's size, not the board's).

**Why it blocks** — a look call: the two readings are both defensible and differ on screen. It
does NOT park a thread: S12 built the viewer-size reading (recorded in ASSUMPTIONS.md) and the
Phase 3 review fix makes the open viewer re-publish its highlight on a container rect change, so
whichever reading wins is one line per viewer to switch.

**Options I can see** — **(a)** the board's card size everywhere, as `Q34`=(b) says literally — every
description looks the same, the viewers pass `PlayArea.board_card_window_px()` (the map's choice
viewer uses the size the map's own entries use) · **(b)** the viewer's own drawn card size — the
preview matches the object under the pointer, and is bigger inside the deck viewer than on the
board · *my recommendation* (b), because "reads as the same object" is the reason the owner gave
**Blast radius** — `UI/deck_viewer.gd`, `UI/choice_viewer.gd`, `UI/cards_viewer.gd`
(`card_window_px()`), one TestSidebar row asserting the preview's drawn width; design node C5
**Meanwhile** — (b) is built and stays until the owner rules
